# BiliTube PRD
当前版本：v1.0.0
里程碑：v1.0

## 1. 项目目标

做 **B 站 AI 大模型视频的「值不值得看」决策层**：从海量 AI 相关视频里，用机器信号 + 文本理解 + 内容理解三层评估，筛出真正的教程、实战与测评，给出结构化卡片与反算法排序。

核心价值：用户不必在几百万条视频里大海捞针，打开就知道"学什么、按什么顺序、哪条值得花两小时"。排序不按播放量，按内容密度与可复用性。

## 2. 业务范围

### ✅ In Scope（做什么）

**内容边界**

- 只做 AI 大模型方向：教程课程、实战工程、工具测评与行业动态
- 时间窗口：近 24 个月为主 + 历史经典少量保留（经典需满足高收藏率分位且内容分达标，人工确认）
- 数量不设硬上限，按质量阈值决定，宁缺毋滥（预计 300–800 条）

**数据发现（三路并集）**

- 关键词搜索：关键词矩阵（大模型、LLM、RAG、Agent、微调、LoRA、SFT、推理加速、vLLM、Transformer 等），按收藏排序与播放排序各取一轮
- 分区榜单：科技区（rid=188）、知识区（rid=36）的近期榜，只用于发现新内容
- 种子扩展：优质 UP 主与系列合集，作为补充来源

**质量评估（三层）**

- 第一层 机器信号：收藏率、投币率、点赞率、讨论率（评论 + 弹幕）、播放量对数
- 第二层 文本理解：标题 / 简介 / 评论 → LLM 判断内容类型、是否标题党、是否搬运、是否合集拼凑、是否过时
- 第三层 内容理解：字幕（优先）→ LLM 评估信息密度、实操性、准确性、时效
- 降级链：字幕不可用 → 弹幕 + 评论 + 简介；并在卡片上标注评估依据

**硬性过滤（在打分之前）**

- 已删除、不可见、付费墙内容
- 时长 < 3 分钟且不属于任何系列
- 标题命中引流词库（最全、最细、零基础全套、七天速成、必看、99% 的人不知道等）
- UP 主粉丝数 < 1000 且播放量异常偏高
- 搬运、合集拼凑、营销号（LLM 判定 + 规则兜底）
- 同一 UP 主收录条数上限（按质量分取前 N 条）

**卡片与站点**

- 每视频一张卡片：摘要、为什么值得看、适合谁、前置知识、难度、时长、时效性、评估依据
- 精选清单页（按主题分组）+ 筛选（类型 / 难度 / 时长 / 年份 / 收藏率）
- 关键词 + 语义混合搜索
- 本地收藏与观看记录（无账号）
- 视频详情页：B 站播放器 + 卡片 + 关键评论摘录

### ❌ Out of Scope（不做什么）

- 账号、登录、服务端用户数据
- 用户评论、弹幕发送、上传、投稿
- 视频与封面的转存、代理、缓存（仅 iframe 播放）
- 全站全量视频覆盖（只覆盖 AI 大模型关键词域）
- 论文解读 / 学术向内容（v1.1 再考虑）
- 移动端 App / 小程序
- 商业化、广告、付费墙

## 3. 用户与使用场景

| 用户角色 | 场景描述 | 期望结果 |
| ---- | ---- | ---- |
| 想入门大模型的开发者 | 面对几百集"零基础全套教程"不知道从哪开始 | 10 分钟内拿到一条可信的入门路径 |
| 要做 RAG / Agent 的工程师 | 需要能照着做的实操教程，而不是概念科普 | 找到有代码、有步骤的实战视频 |
| 跟进工具与模型的技术人 | 想知道最近哪些模型、框架值得关注 | 看到近期高质量测评，而不是营销稿 |
| 想补基础的进阶者 | 需要判断一条老视频是否还值得看 | 卡片直接给出时效标签 |

## 4. 功能清单

### 模块 A：采集（COL）

- F-COL-1 关键词搜索采集：按关键词矩阵调用搜索接口，支持按收藏 / 播放排序，单关键词上限 1000 条
- F-COL-2 分区榜单采集：科技区、知识区近期榜
- F-COL-3 种子扩展：从指定 UP 主与系列合集扩展候选
- F-COL-4 详情补全：统计数据、分区、时长、发布时间
- F-COL-5 评论采集：热门评论，用于口碑判断
- F-COL-6 弹幕采集：观众反应信号，字幕不可用时兜底
- F-COL-7 字幕采集：优先获取 CC / AI 字幕；失败降级

### 模块 B：归一与去重（NRM）

- F-NRM-1 视频归一：BV / av 统一、短链解析
- F-NRM-2 系列合并：同一课程的多分 P 与多版本合并
- F-NRM-3 搬运识别：标题 / 简介 / UP 相似度 + LLM 判定
- F-NRM-4 失效过滤：已删除、仅会员、时长异常

### 模块 C：质量评估（QAL）

- F-QAL-1 指标计算：收藏率、投币率、点赞率、讨论率、播放量对数
- F-QAL-2 分位归一：按"分区 × 时长档"计算百分位，避免绝对值阈值失真
- F-QAL-3 内容分类：教程 / 实战 / 测评 / 新闻 / 标题党 / 搬运 / 广告 / 合集拼凑
- F-QAL-4 内容打分：信息密度、实操性、准确性、时效性（0–100）
- F-QAL-5 综合分：加权合成 + 惩罚项，输出排序与推荐理由
- F-QAL-6 人工抽检：抽样复核并记录一致率，用于校准阈值

### 模块 D：卡片生成（CRD）

- F-CRD-1 卡片字段：摘要、为什么值得看、适合谁、前置知识、难度、时长、时效、评估依据
- F-CRD-2 主题归类：AI 大模型主题树（基础 / 微调 / RAG / Agent / 推理 / 工具 / 生态）
- F-CRD-3 过时标注：标注"已被新技术取代"并指向替代视频

### 模块 E：检索（IDX）

- F-IDX-1 关键词索引：标题、UP、主题、卡片文本
- F-IDX-2 语义检索：中文向量，支持自然语言查询
- F-IDX-3 筛选与排序：难度、时长、年份、收藏率、综合分

### 模块 F：站点（WEB）

- F-WEB-1 首页：编辑型首屏（数量口径 + 方法一句话）+ 编辑首选头条 + 精选网格 + 主题筛选
- F-WEB-2 详情页：播放器、评分双条、编辑手记（为什么值得看 / 适合谁 / 前置 / 难度 / 时效）、同主题推荐
- F-WEB-3 搜索与筛选（标题、UP、卡片内容；主题、排序）
- F-WEB-4 本地收藏 / 观看记录
- F-WEB-5 响应式（1024 / 720 两档）、`/` 聚焦搜索、`prefers-reduced-motion` 降级；深色模式跟随系统并可手动切换（ADR-019）
- F-WEB-6 静态构建：构建期生成 JSON 分片，无运行时后端

### 模块 G：数据开放（DATA，v1.1）

- F-DATA-1 `/data` 页与 `DATA.md`
- F-DATA-2 导出脚本

## 5. 非功能需求

- 性能：本地全量构建 ≤ 30 分钟；首页 LCP < 2s；搜索 < 200ms
- 可靠性：采集断点续采、幂等重跑；字幕 / 评论 / 弹幕任一失败均可降级
- 安全与合规：Cookie 与密钥只存本地 `.env`，不入库不导出；不转存视频与弹幕原文；不公开展示完整评论原文，仅摘录
- 可观测：采集 / 评分 / 构建三阶段日志与统计报告
- 兼容性：Windows 10/11 单机；Python 3.12；Node 20+
- 成本：LLM 总花费 ≤ 30 美元
- 语料边界：只处理中文与中文字幕内容，不做外语自动翻译
