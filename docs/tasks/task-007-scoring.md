## 执行步骤

1. 定义分位分组：`分区（tname_v2）× 时长档（<10min / 10–30 / 30–90 / >90）`
2. 计算五个指标的分位：收藏率、投币率、点赞率、讨论率（评论 + 弹幕）、播放量对数
3. 指标缺失（如收藏数为 0）时按 0 处理，不参与分位但记录 `flags`
4. 机器分 = 0.30×收藏率分位 + 0.25×投币率分位 + 0.15×点赞率分位 + 0.15×讨论率分位 + 0.15×播放量分位，归一到 0–100
5. 分组样本数 < 30 时退化为全站分位，并在 `flags` 标注 `low_sample`
6. 写入 `scores` 表（content 先留空），输出分数分布与 TOP 20 抽样

## 验收标准（布尔判定）

- [ ] `scores` 表中机器分全部落在 0–100
- [ ] 同一分组内，收藏率更高的视频分位不低于收藏率更低的
- [ ] 分组样本不足时自动退化并标注 `low_sample`
- [ ] 重复执行结果一致
- [ ] 输出 TOP 20，人工判断其中至少 12 条与 AI 主题相关
- [ ] 单元测试覆盖分位计算与边界（全相同值、单条样本、缺失值）

## 评测方案

- 单元测试：构造已知分布，断言分位值正确
- 人工抽检：查看 TOP 20，对照标题与分区判断合理性
- 数据校验：分数分布直方图与分组样本数统计
