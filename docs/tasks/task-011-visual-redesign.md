# TASK-011 站点视觉重做：编辑型版式与封面

- 编号：TASK-011
- 里程碑：v0.2.0
- 前置依赖：TASK-010
- 优先级：🟠 P1
- 状态：✅ done
- 来源：用户反馈「页面显得草率，色系和布局不够优雅，卡片没有视频截图」
- 关联文档：architecture.md ADR-015、ADR-016；api-contract.md「数据产物契约」

## 背景

首版站点以深色面板 + 圆角卡片呈现，用户第一次打开无法判断「这是一个视频站」，也不认可其视觉气质。问题拆开是三条：

1. 信息层级平：标题、卡片、筛选控件视觉权重接近，没有头条
2. 缺少封面：卡片只有文字，视频属性不明显
3. 没有解释「这是什么、为什么信」：首屏直接是工具条 + 列表

## 执行步骤

1. 数据侧：`raw_videos` 增列 `cover`（迁移 v4，从 `raw_json.pic` 回填），搜索与详情链路都归一化写入；`export` 增加 `cover` 字段与 `meta.candidates/danmaku_rows/covers`
2. 设计令牌：`web/app/globals.css` 重写为纸张 / 墨色 / 朱红三色体系，衬线标题 + 系统无衬线正文 + 发丝线分隔，取消阴影与渐变
3. 首页：新增编辑型首屏（eyebrow / 大标题 / lede / 四项硬指标），首条为「编辑首选」头条，其余为三列网格
4. 卡片：16:9 封面（`referrerPolicy=no-referrer`、`@672w_378h_1c.webp` 缩略图）、左下内容类型标签、右下时长、hover 播放键；标题 2 行 + 判断 2 行 + UP/综合分页脚
5. 筛选：搜索框（`/` 快捷键聚焦）、排序文字页签、主题 chip（默认收起、可展开全部 80 个）、结果行与「清除筛选」
6. 详情页：两栏（播放器 + 粘性侧栏），侧栏含大号综合分与内容/互动双条、数据表、主题跳转、收藏与「在 B 站打开」；下方「编辑手记」以衬线引文呈现 `why`，再列 适合谁/前置/难度/时效/类型，底部「同一主题」推荐 3 条
7. 状态与降级：加载骨架屏、空结果态、无封面占位、`prefers-reduced-motion` 降级

- [x] 搜索、主题、排序、翻页、清除筛选五条路径可用
- [x] 详情页显示评分双条、编辑手记、相关推荐
- [x] 宽度 1024 / 720 两档下网格降为 2 列 / 1 列，无横向溢出

## 评测方案

- 构建校验：`npm run build` 退出码 0；`pytest -q` 全绿
- 数据校验：`meta.json.covers == meta.json.videos`
- 人工验收：桌面宽度下走首页 → 头条 → 卡片 → 详情 → 相关推荐 → 返回；查看封面是否加载、hover 是否有播放键
- 视觉验收：与旧版截图对照，确认层级、配色、留白变化符合预期
